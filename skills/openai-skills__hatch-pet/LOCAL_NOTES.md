# 本地使用说明（openai-skills__hatch-pet）

- 上游依赖 `$imagegen` 系统技能（按实际调用可能产生 API 费用/上传提示词）、web 搜索做品牌调研、以及 8 个 Python 脚本。本环境**无 imagegen、无网络、不运行脚本**。
- 可用部分：**规范与方法论**——8x9 图集几何、9 行动画状态与时长、QA 评分表、pet.json 打包结构、品牌线索转提示词的写法（见 `references/`）。
- `allowed_tools` 仅 `read_file`：不调用图片 API、不写 `~/.codex/pets/`、不执行 `scripts/*.py`、不上传任何图片。
- 需要真实出图时，请用户自行准备图片生成工具或提供图片，再按规范验收。
- 品牌调研类请求：本环境不联网，只能给出检索提纲与提示词，不编造品牌事实。
