# 《星港回收站》游戏设计说明

## 游戏概要
- **类型**：回合制网格探索游戏
- **目标**：收集3个芯片后到达出口获胜
- **规则**：
  - 玩家初始HP=5，能量=12
  - 移动消耗1能量，等待恢复1能量
  - 能量耗尽时只能等待
  - 敌人接触造成伤害（同一回合不重复伤害）
  - 视野半径3
  - 地图18列×12行，每格32像素

## 引擎契约
- 导出 `Game` 类
- 构造函数：`new Game({seed, width, height})`
- 公开属性：
  - `player`: {x, y, hp, energy}
  - `enemies`, `chips`, `collected`, `turn`, `status`, `grid`, `seed`
- 方法：
  - `move(dx, dy)`: 移动
  - `wait()`: 等待恢复能量
  - `serialize()`: 序列化状态
  - `Game.fromJSON(string)`: 恢复状态

## 实现计划（阶段1）
1. 实现核心游戏逻辑和地图生成
2. 支持移动、等待、敌人行动
3. 实现序列化/反序列化
4. 编写测试用例覆盖种子复现、可达性、无效移动不推进回合等

## 约束
- 所有文件写入工作区相对目录 `context-handoff-game-20261016-154228/`
- 仅使用原生HTML/CSS/JS，无CDN和外部素材
- 引擎支持Node和浏览器加载（CommonJS格式）
- 随机数生成器必须可重复（伪随机）
